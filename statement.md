# Project Statement

## Problem Statement

Academic information such as student profiles, marks and attendance is often maintained manually or across separate files. This makes searching, updating and reporting difficult.

## Scope

CampusDesk provides a centralized desktop application for managing student profiles, marks, attendance and academic reports.

## Target Users

- Teachers
- Academic administrators
- Students (future extension)

## High-Level Features

1. User login
2. Student CRUD
3. Marks management
4. Attendance management
5. Academic analytics
6. CSV/JSON export
7. HTML report generation
8. Validation and exception handling

## Objectives

- Apply Python programming concepts to a practical problem.
- Demonstrate object-oriented programming.
- Demonstrate file and database handling.
- Build a GUI using Tkinter.
- Implement validation and testing.
- Produce useful academic reports.
